# AGENTS.md

Shared instructions for all AI coding agents (Cline, Claude Code, Codex, Gemini).

Maintenance Copilot is an AI agent that answers maintenance-engineering questions by combining
work orders, sensor data and equipment manuals, citing a source for every claim. It is a personal
learning project built on public data (NASA C-MAPSS) and synthetic data (work orders, manuals).

## Rules

1. Never read, print or commit secrets (`.env`, `.streamlit/secrets.toml`). Use `.env.example`
   to see which variables exist.
2. Only synthetic or public data. Never use real company or employer data.
3. Keep the agent and the SQL tool read-only.
4. Never change eval answers or checks just to make a run pass.
5. Run `uv run pytest` before committing. All tests must pass.
6. Make the smallest change that solves the task.

## Commands

Use `uv run` for everything. Python 3.12, line length 100, lint with ruff.

```bash
uv sync                                    # install pinned deps (add --extra openai / --extra google)
uv run mc setup                            # build local data, RUL model, ground truth (~5 s, no API cost)
uv run mc app                              # Streamlit chat UI at http://localhost:8501 (API cost per question)
uv run mc ask "question"                   # one question in the terminal (API cost)
uv run mc mcp                              # serve the tools over MCP (no API cost)
uv run pytest                              # offline tests, no API key needed, free
uv run ruff check . && uv run ruff format --check .
uv run mc eval --agent null --trials 1     # free baseline, no LLM calls
uv run mc eval                             # COSTS MONEY: full run, 54 LLM runs, ~$2 on Opus
uv run mc eval --agent copilot-mcp         # COSTS MONEY: same agent, tools over MCP
uv run mc eval --rescore <LOG>             # free: re-score a stored run log
```

Do not run the paid commands unless the user asks. Use `--case <id>` and `--trials 1` to keep
cost down.

## Where things live

```
src/maintenance_copilot/
  agent.py        LangGraph agent loop (max 8 tool rounds)
  prompts.py      system prompt
  llm.py          provider switch via LLM_PROVIDER / LLM_MODEL env vars
  tools/          the three tools: work_orders (read-only SQL), sensors, manual_search
  rul.py          remaining-useful-life model
  manuals.py      BM25 manual search
  data/           generators, NASA download, ground truth
  evaluation.py   eval harness
  mcp_server.py   MCP server; mcp_bridge.py serves agent tools over MCP
  app.py, cli.py  Streamlit UI and the `mc` CLI
manuals/          3 synthetic equipment manuals (committed)
evals/            cases.toml, results/, FAILURES.md; runs/ is git-ignored
tests/            offline pytest suite
data/             generated by `mc setup`, git-ignored; never commit
```

## Workflow

1. Create a branch from `main` (`feat/...`, `fix/...`, `chore/...`). Never commit to `main`.
2. Make small, focused commits with clear messages.
3. Run `uv run pytest` and `uv run ruff check .` before pushing.
4. Open a PR with a short description: what changed and why. Add a CHANGELOG.md entry for
   user-visible changes.
